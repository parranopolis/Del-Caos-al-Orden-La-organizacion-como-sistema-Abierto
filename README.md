# SISTEMA: El Sistema Abierto Organizacional

Revista digital interactiva desarrollada para evaluar la aplicabilidad de la Teoría General de Sistemas (TGS) y la Teoría del Caos dentro del entorno organizacional. 

Este proyecto conceptualiza a la empresa como un sistema abierto, analizando la tensión constante entre el desgaste natural de sus procesos (entropía) y la inyección de información y energía estructuradora (neguentropía) necesaria para su supervivencia.

## 🛠 Características Técnicas

El proyecto fue diseñado bajo un enfoque de desarrollo minimalista y de alto rendimiento, eludiendo el uso de editores gráficos o CMS tradicionales:

* **Cero Dependencias:** Construido puramente con HTML5, CSS3 moderno y Vanilla JavaScript.
* **Arte Generativo Integrado:** Incluye algoritmos matemáticos en JavaScript para renderizar dinámicamente gráficos vectoriales (SVG), destacando la generación de un Atractor de Lorenz para ilustrar la Teoría del Caos.
* **Diseño Responsivo:** Maquetación fluida utilizando CSS Grid, Flexbox y tipografía escalable (`clamp`).
* **Theme Toggle:** Soporte nativo para Modo Oscuro / Claro gestionado mediante variables CSS (`:root`) y detección de preferencias del sistema (`prefers-color-scheme`).
